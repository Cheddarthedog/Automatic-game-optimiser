# Automatic-game-optimiser
An automatically applying and running optimisation service for steam or proton games. 
Uses python

Works natively on Linux Mint

Cross distro-compatability will be added when inital program is finalised

Install the source and run the install script. The program will automatically install to the right directory and create a startup service. Root access is required for full functionality.
